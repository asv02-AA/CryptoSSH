CryptoSSH 1.0.0

Нативный SSH-клиент для Windows x64.
Собственный код CryptoSSH распространяется по лицензии MIT. Полный текст находится в файле LICENSE в папке приложения.

SSH.NET, Pkcs11Interop, Bouncy Castle и .NET распространяются по своим открытым лицензиям. Тексты лицензий находятся в папке licenses; перечень компонентов — THIRD-PARTY-NOTICES.md.

Драйверы и библиотеки Рутокен и JaCarta в этот дистрибутив не входят. Установите официальное ПО только нужного производителя самостоятельно и укажите x64-библиотеку PKCS#11 в настройках. Достаточно одной библиотеки; для входа по паролю или файлу ключа они не нужны.

CryptoSSH — независимый проект, не официальный продукт компаний «Актив» и «Аладдин Р.Д.». Программа предоставляется без гарантий согласно лицензии MIT.
