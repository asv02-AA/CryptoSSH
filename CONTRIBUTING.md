# Участие в CryptoSSH

Ошибки и предложения принимаются через GitHub Issues. Перед созданием issue проверьте существующие обращения и README. Укажите версию клиента, Windows, модель токена, версию и разрядность библиотеки и минимальные шаги воспроизведения. Удаляйте PIN, пароли, закрытые ключи, реальные адреса и серийные номера из логов и снимков.

Для изменения кода создайте ветку и pull request. Опишите проблему, результат и выполненные проверки. Инструкции сборки находятся в README, интеграционных тестов — в VERIFICATION.md. Аппаратные операции проверяйте только на своём тестовом токене; автоматические тесты должны использовать изолированное хранилище SoftHSM.

Не добавляйте DLL/установщики производителей, секреты, пользовательские профили или результаты сборки. Сохраняйте существующие уведомления об авторских правах. Изменения собственного кода предоставляются по MIT, как и проект.

Уважайте участников, обсуждайте технические решения без личных нападок. Сообщения об уязвимостях направляйте по SECURITY.md.
