# Проверка CryptoSSH

## Воспроизводимые проверки

На Windows после сборки:

```powershell
powershell -File scripts/test-native.ps1
```

Скрипт проверяет сохранение профилей, миграцию, оформление, VT-парсер, работу с host keys, независимый выбор библиотек и отсутствие DLL производителей в релизе. Затем запускает WPF smoke test с вводом с клавиатуры и снимками интерфейса. Нужен интерактивный рабочий стол. Для CI без интерактивного рабочего стола используйте `-CoreOnly`.

Для SSH-интеграции установите Node.js и тестовую зависимость:

```powershell
Push-Location tests/ssh-fixture
npm.cmd ci
Pop-Location
powershell -File scripts/test-native.ps1 -Integration
```

Локальный ssh2-сервер слушает только loopback. Ключи и данные создаются в `artifacts/`, не публикуются и не входят в клиент.

Для PKCS#11 требуется отдельная тестовая установка SoftHSM2 для Windows (x64), содержащая `lib/softhsm2-x64.dll`, `lib/softhsm2.dll` и `bin/softhsm2-util.exe`:

```powershell
powershell -File scripts/test-pkcs11.ps1 -SoftHsmRoot C:\Tools\SoftHSM2
```

Скрипт создаёт изолированное хранилище SoftHSM и тестовые PIN, генерирует RSA, экспортирует публичный ключ и проверяет подпись, повторные ID и дубликаты публичных объектов. Затем проверяет SSH-подключение с одним включённым провайдером по отдельности для обоих маршрутов. Это не аппаратная проверка конкретной модели Рутокен/JaCarta. Не подменяйте тестовые пути реальным рабочим токеном.

Проверка кодировки текста собранного NSIS-установщика (Python 3, без сторонних пакетов):

```powershell
python scripts/verify-installer.py
```

## Что требует ручной проверки

- Совместимость конкретной модели и версии middleware на физическом устройстве.
- Windows SSH-agent с реальными ключами агента.
- Работа сложных полноэкранных TUI: полной совместимости xterm не заявлено.
- Установка/обновление на чистой Windows без ранее установленного middleware.

Результаты проверки публичного релиза приведены в его release notes. Снимки тестов могут содержать сведения о подключённых устройствах; не публикуйте их без проверки и обезличивания.
