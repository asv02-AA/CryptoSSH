# Changelog

## 1.0.0 — 2026-09-29

Первый публичный релиз CryptoSSH для Windows x64.

- Нативный WPF-интерфейс и собственный терминал; SSH.NET внутри приложения.
- Рутокен и JaCarta через внешние x64 PKCS#11-библиотеки: можно настроить только одного производителя или обоих.
- Обнаружение устройств, выбор токена и ключа при подключении, генерация RSA и экспорт существующей публичной части.
- Корректное сопоставление RSA-ключей с повторяющимися ID, объединение дубликатов публичных объектов и локальная проверка подписи.
- Подключения по паролю, файлу ключа и Windows SSH-agent; профили, группы, избранное, вкладки и команды.
- Темы терминала и пользовательские цвета, индикатор операций с токеном, диалоги завершения сессии в теме интерфейса.
- Автоматическое доверие при первом подключении; подтверждение продолжения при изменении ключа сервера.
- Драйверы и библиотеки производителей исключены из исходников и дистрибутива. Пользователь устанавливает их самостоятельно.
- Исправлена кодировка русского текста установщика. Настройки ранних локальных версий сохраняются.
