# Безопасность

Исправления безопасности планируются для последней опубликованной версии. Независимого аудита и сертификации у проекта нет; срок ответа не гарантируется.

Для сообщения об уязвимости используйте вкладку **Security → Report a vulnerability** в GitHub (private vulnerability reporting). Не публикуйте рабочий эксплойт или секреты в обычном issue. Укажите версию, условия воспроизведения, влияние и безопасный пример без реальных учётных данных.

Особенности 1.0.0:

- Первый ключ SSH-сервера принимается автоматически (TOFU); смена ключа требует подтверждения. Это не независимая проверка первого подключения.
- Пароли/PIN не сохраняются на диск, но используются в памяти во время сеанса. Профили и команды в локальном JSON не зашифрованы.
- Произвольная PKCS#11 DLL выполняется в процессе клиента. Используйте официальный пакет и x64-библиотеку производителя.
- Команды из сохранённого списка выполняются сразу при выборе. Не храните в них секреты.
- Закрытый RSA-ключ генерируется на токене с Sensitive=true / Extractable=false; реальная защита зависит от устройства и его ПО.
